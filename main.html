SYS-01 // PERFORMANCE OPTIMIZATION v0.9 R&D

OptiSim

Climb & Vertical Profile Optimization Engine

The flight simulator counterpart to real-world airline climb optimization (OptiClimb). OptiSim ingests SimBrief Operational Flight Plans (OFP), airframe-specific aerodynamic performance tables, and upper-air wind/ISA temperature profiles to compute cost-index-aligned IAS/Mach climb schedules that reduce trip fuel burn.

SYSTEM CAPABILITIES
01 SimBrief OFP XML/JSON flight plan, Cost Index, and payload ingestion
02 Multi-level winds aloft & ISA temperature deviation modeling
03 Airframe-calibrated drag polars and fuel-flow climb schedules

SYS-02 // ELECTRONIC FLIGHT BAG v0.8 R&D

SmartEFB

Cross-Platform Electronic Flight Bag Suite

Designed for simultaneous operation on desktop workstations (secondary monitor or overlay) and external tablet/mobile devices over local network sync (PWA / WebSocket). Integrates SimBrief dispatch briefings, interactive operational checklists, airport briefing workflows, and flight deck utilities.

02 // SYSTEM ARCHITECTURE

Engineering Standards & Design Principles

01 // RUNTIME LOCAL-FIRST

Zero-Bloat Local-First Execution

All performance solvers and EFB services execute natively on local hardware without mandatory cloud subscriptions or heavy background telemetry daemons—preserving CPU and GPU headroom for MSFS 2020/2024, Prepar3D, and X-Plane 12.

MEM FOOTPRINT: < 85 MB // NO CLOUD LOCK-IN
02 // COMPLIANCE EASA / ICAO

Real-World Aeronautical Standards

Data structures, climb speed schedules, and Electronic Flight Bag checklists are architected in strict alignment with EASA/ICAO operational conventions, Flight Crew Operating Manuals (FCOM), and airline dispatch SOPs.

STANDARDS: ICAO DOC 8168 • FCOM / QRH LOGIC
03 // TOPOLOGY MULTI-CLIENT

Cross-Device Synchronization

A unified local-network host architecture synchronizes active flight plans, checklist states, and performance calculations in real time between your primary simulator PC workstation and external iPad or Android tablets.

PROTOCOL: HTTP/WS LOCAL LAN BRIDGE
